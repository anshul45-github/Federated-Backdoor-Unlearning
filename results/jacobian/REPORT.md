# JVP-Cal experiment report: correction and interim status

**The earlier report's JVP conclusions are invalid.** The original runner used the historical client update as the Taylor displacement instead of the difference between the replayed and historical global models. In addition, the run named iid_fed_e1 actually used two local epochs. Those outputs are preserved for provenance but must not be used as JVP-Cal or E_cal=1 results. The runner is corrected and new outputs have corrected_ prefixes.

The corrected IID GGN first-order run with Bc=64, one effective step, norm scaling, and estimator seed 123 recorded 64.75% clean accuracy and 1.644444% ASR, in 11.322779 seconds of round processing (corrected_iid_ggn_s123/metrics.json). Same-trajectory stale replay was 67.08% and 0.466667% (iid_stale/metrics.json). The corrected one-step choice does not model the full local momentum-SGD process. Correctly labeled baselines and other runs are still being generated by scripts/proposed/run_all.sh; no final L0/L1/L2 verdict, FLOP claim, or hyperparameter selection is yet supported.

Regenerated trajectories each contain 500 client deltas. IID attack: 74.90% CA and 50.611111% ASR; Non-IID: 70.80% CA and 30.022222% ASR (each setting's final_results.json). Baselines must use those trajectories, not historical checkpoint summaries with different provenance.

The corrected estimator uses old-trajectory or midpoint parameters, eval-mode BN, historical BN deltas, and fixed client-specific subsample indices. It does not yet implement train-mode curvature, BN recomputation, validation-based selection, a verified FedRecover baseline, FLOP accounting, or all requested ablations. Current oracle diagnostic uses a full two-epoch counterfactual but only eight curvature samples and is not an exhaustive oracle. Running on one trajectory seed and one dataset/model limits generality. See docs/jacobian/NOVELTY_CHECK.md for the prior-art check.

Four unit tests passed (see logs/corrected_pipeline.log): explicit GGN, exact HVP finite difference, two-step quadratic Taylor recurrence, and eval-mode real-model GGN/buffer smoke. Environment: Python 3.12.9 and torch 2.9.0+cu128, deviating from README pins. Per-round runtime excludes setup and evaluation and is not a FLOP measurement.

Reproduce from /home/teaching/isp: nohup setsid env PYTHONUNBUFFERED=1 bash scripts/proposed/run_all.sh > logs/corrected_pipeline.log 2>&1 < /dev/null &. The script checks both trajectory counts, runs tests, uses distinct per-stage markers and resumes from round checkpoints. Existing attack regeneration is a prerequisite; it is not itself restartable from this script. Inspect logs/corrected_pipeline.log and completion markers for progress.
